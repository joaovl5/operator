# ¡!¡ This is not done ¡!¡

And it won't be... at least, not for now, and not from this codebase.
This is part of the code I've worked on a few months ago. Much of it
is tech debt, and some of it possible ideas I will reuse when
attempting to explore the subject matter in the future. Ironically
enough, even though `operator` is an "agentic" coding harness, I tried
to minimize any such assistance during work, since I'm more interested
in the low-level parts which LLMs have already allegedly solved.

I was also kind of annoyed in some points with the problems in the
type system of Python, which is very iffy at times, and it's not as
powerful as I'd liked for expressing some things. My next project for
something like this probably ought to be in a language like Rust or
Haskell.

In short: I'm publicizing this in case any of this becomes of use, in
the same sense a scrapyard can be picked for parts. Notably, there's a
`le_pipes` module which was is a hack for having pipe operator-like
syntax in Python, with as much typed-guarantees as allowable.
